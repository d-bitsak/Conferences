# Практикум «Три малые проектные команды»

За 10–15 минут вы составите план внедрения ИИ на ближайшие три месяца: до трёх проектов с быстрым результатом и команда на каждый из них. Codex проведёт интервью и поможет довести формулировки. Для участия достаточно знать людей и задачи своей компании; готовить документы или писать код не нужно.

## Установка через Codex

1. Распакуйте архив `form-small-project-teams-codex.zip` на компьютере.
2. Откройте в Codex локальную папку проекта, где будете проходить упражнение. Скопируйте в неё папку `form-small-project-teams` из архива.
3. Отправьте в чат Codex этот текст:

```text
Установи локальный скилл из папки form-small-project-teams в текущем проекте: скопируй её целиком в .agents/skills/form-small-project-teams. Проверь, что там есть SKILL.md и agents/openai.yaml. Если по этому пути уже есть скилл, сначала сравни содержимое и не перезаписывай отличающиеся файлы без моего решения. После установки сообщи результат.
```

4. Начните новый чат в том же проекте и отправьте:

```text
Используй $form-small-project-teams. Проведи меня через упражнение по сборке трёх малых проектных команд в моей компании.
```

Если скилл не появился, перезапустите Codex и снова откройте этот проект.

## Ручная установка

В папке проекта создайте каталоги `.agents/skills` и поместите внутрь папку скилла целиком. Должна получиться структура:

```text
ваш-проект/
└── .agents/
    └── skills/
        └── form-small-project-teams/
            ├── SKILL.md
            └── agents/
                └── openai.yaml
```

Чтобы скилл был доступен в разных проектах, вместо установки в проект можно поместить ту же папку в `.agents/skills` внутри домашней папки пользователя. Не устанавливайте обе копии одновременно без необходимости: они могут отображаться как два скилла с одинаковым именем.

Пути установки и обнаружение скиллов сверены 19 сентября 2026 года с [официальной документацией OpenAI](https://learn.chatgpt.com/docs/build-skills).

## Как проходить упражнение

На каждый вопрос Codex даёт шаблон ответа: скопируйте его, заполните и отправьте. Можно ответить и свободным текстом — Codex сам разложит ответ по полям. О людях достаточно имени и фамилии, о ВПП — ФИО и должности; можно использовать инициалы и условные обозначения. Если чего-то не знаете, напишите «уточнить».

Codex последовательно проведёт вас по четырём блокам вопросов:

1. Определить до трёх проектов на ближайшие три месяца — по одному: сначала самый важный, затем второй и третий. Главный критерий отбора — быстрая победа: результат виден в пределах трёх месяцев. По каждому проекту — название, что сейчас не работает и что должно появиться.
2. Назвать владельца портфеля проектов (ВПП) — того, кто определяет, куда тратить ресурсы, и отвечает на вопрос «Нужно ли делать?».
3. Назвать заказчика каждого проекта — того, кому больше всех нужен результат («Что делать?»).
4. Назвать исполнителя каждого проекта — того, кто делает руками, в том числе с помощью AI-агентов («Как делать?»).

На выходе вы получите одну таблицу: проект, проблема, идея, ВПП, заказчик, исполнитель. Codex ничего не придумывает за вас: проекты, люди и сроки берутся только из ваших ответов, а свои формулировки он показывает на подтверждение. При доступе к записи Codex также сохранит таблицу в Markdown-файл в рабочей папке. Назначения предварительные: после практикума их нужно обсудить с выбранными людьми.

Если у вас меньше трёх подходящих людей или проектов, упражнение всё равно можно завершить.

## Если установка задерживается

Можно пройти упражнение прямо по файлу. Оставьте распакованную папку скилла в текущем проекте и отправьте:

```text
Прочитай form-small-project-teams/SKILL.md и проведи меня через описанное в нём упражнение. Начни с первого этапа и дождись моего ответа.
```

Это запускает сценарий по файлу для текущего чата, но не устанавливает скилл для других чатов.
