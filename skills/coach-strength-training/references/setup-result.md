# Карточка готовности тренировочного помощника

Показывать после завершения мастера, при технической блокировке, изменении настройки и команде «покажи настройки». Не добавлять к каждой тренировке и не выдавать после обычного уточняющего вопроса.

Строить только по перечитанным личным настройкам, manifest и реальным результатам проверок. Не использовать пустой пример, запрошенную функцию или согласие пользователя как доказательство её работы.

## Статусы

| Общий статус | Условие |
| --- | --- |
| Готов к работе по команде | Выбран такой способ и есть достаточные данные для доступного тренировочного сценария |
| Настроен | Все выбранные функции проверены и разрешены; для вечера дополнительно подтверждены реальный запуск и личный канал |
| Частично настроен | Работает часть желаемых функций, остальные не готовы; явно назвать обе части |
| Настройка приостановлена | Запрошенный способ пока недоступен и применимый источник/вариант работы не подтверждён |

Если хотели WHOOP, а доступен только тренер, не писать «Всё настроено». Разделять готовность программы, дневника, метрик и расписания. Не выдавать сохранение профиля за сохранённые занятия.

## Шаблон

Удалять неприменимые строки, не выводить пустые заполнители и лишние технические детали.

```markdown
**Силовой тренер — {общий статус}**

| Параметр | Результат |
| --- | --- |
| Как пользоваться | {По команде / по команде и вечерний отчёт / доступная часть} |
| Программа | {Подтверждённая цель, структура, время и оборудование} |
| История | {Источник; сколько разных подтверждённых занятий учтено; имеющиеся пробелы} |
| Дневник | {Проверенное личное место; запись разрешена и проверена / конкретный предел} |
| WHOOP | {Не выбирался / проверено подключение и разрешение / конкретная блокировка} |
| Платные запросы | {Бюджет и предел попыток; только если WHOOP выбран} |
| Вечерний отчёт | {Фактически включённые время, IANA-зона, ближайший запуск и личный канал либо честный статус} |
| Настройки | {Сохранены и доступны следующим запускам / только в беседе / что не проверено} |

**Проверено:** {2–4 конкретных результата}.

**Требует действия:** {Одна проблема, что она блокирует и следующий шаг; только при наличии}.

**Первая команда:** «{Применимая короткая команда}».
```

Для непроверенной возможности писать «Не проверено» и последствие; не выводить account IDs, токены, медицинские подробности, внутренний JSON и ключи резервирования. Дневник/канал называть понятным личным назначением; не публиковать его частную ссылку в распространяемый комплект.

Для WHOOP различать: подключение видно; бюджет разрешён; платный тест выполнен/не выполнялся; данные получены и сохранены. Если настроено лишь расписание и первого запуска не было, написать «Расписание включено и проверено; первый сбор ещё не подтверждён». Запуск не считать бесплатным тестом.

При credit blocked, partial или unknown сохранить реальный статус и пояснить, что повторный сбор не включён. Кредитную блокировку не снимать «для завершения настройки». Без настроенного расписания не обещать вечерний отчёт.

Для базового сценария WHOOP/расходы/вечер можно опустить либо коротко обозначить, если они обсуждались. Пользователю без WHOOP показывать полезный тренировочный результат, а не список ненужных подключений.
