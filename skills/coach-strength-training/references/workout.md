# Тренировка по запросу

1. Прочитай актуальный план и три последних разных занятия до текущего по дате/идентификатору программы. Учитывай completed и partial с фактическими подходами; planned/started без факта не считать. Незавершённое занятие покажи отдельно. Сравни объём, веса, повторения, переносимость и интервалы отдыха. При недостатке данных проверь только выбранные источники; не импортируй всю историю.
2. Проверь доступное время, оборудование, текущую боль и восстановление. Не переспрашивай уже сообщённое. Сохранённые WHOOP-показатели можно учитывать с оговоркой о дате; дополнительный запрос при начале тренировки не предусмотрен.
3. Выдай дату, название программы и короткую логику изменений. Для каждого упражнения: точный вариант/оборудование, рабочие подходы × повторения, вес или способ подбора, отдых, 1–2 подсказки техники. Разминку отдели от рабочих подходов.
   Дату брать из актуального клиентского времени, приведённого к подтверждённой IANA-зоне владельца. Не переносить дату из примера, старой записи или календарной даты сервера без известного момента времени. Если надёжный текущий момент не доступен, назвать результат «План для ближайшего занятия» без выдуманной даты.
4. Вес бери из подтверждённого выполнения того же варианта. Стек разных тренажёров не эквивалентен; вес грифа не угадывай. Для штанги укажи общий вес с грифом, для гантелей — одной гантели. Если неизвестно, явно уточни или предложи безопасный подбор.
5. Прогрессируй небольшим доступным шагом после выполнения объёма с устойчивой техникой, без боли и при достаточном восстановлении. Не повышай сразу вес, объём и сложность. При сомнении повтори/снизь нагрузку. Обычный консервативный ориентир — 2–3 повтора в запасе, не обязательное персональное правило.
6. Субъективная общая сложность занятия не является RPE каждого подхода и не позволяет вычислить запас повторений. Замена сохраняет цель движения и переносимость, но не автоматически прежний вес.
7. Для техники объясни настройки тренажёра, исходное положение, движение, дыхание и безболезненный диапазон. При неоднозначности попроси фото/модель; не выдавай случайное изображение за точное оборудование.

## Программа и форма дневника

Отдельные поля плана и факта: упражнение/вариант, запланированные подходы/повторения/вес/отдых, фактические подходы (повторы и кг либо секунды), выполнено/пропущено, общая сложность, боль/самочувствие и комментарий.

Виджет используй только если принимающая среда реально поддерживает штатную интерактивную поверхность и её доставку в текущем канале. Это представление, не новое хранилище. Не помещай токены в HTML и не вызывай сторонние API из формы.

HTML сам по себе не подтверждает связь с агентом или таблицей. Если проверенного механизма передачи нет, обозначь ввод как локальный черновик и попроси сообщить результат в чате или записать в дневник напрямую. Не показывай фиктивную кнопку «сохранено». Без виджета дай обычную таблицу/текст и ссылку на разрешённый дневник. Не создавай сайт или приложение без команды.
