# Карточка результата настройки


Выдавать при завершении/технической блокировке мастера, изменении настройки и команде «Покажи настройки». Во время обычных уточнений отвечать коротко, не повторять большую таблицу.

## Общий статус


| Статус | Условие |
| --- | --- |
| Готово к планированию по команде | Доступны выбранные источники и личный ответ; остальное соответствует запрошенному базовому сценарию |
| Готово к автоматическому утреннему списку | Все выбранные зависимости проверены, расписание и личная доставка включены/перечитаны, ссылки на настройки доступны запуску |
| Частично готово | Работает часть желаемых функций, другие блокированы/не проверены |
| Настройка приостановлена | Нет применимого источника/способа выполнить запрошенный сценарий |

Не объявлять полную готовность при недоступном запрошенном источнике/календаре или незавершённом переносе. При выборе focus_only отсутствие write-доступа не является блокировкой.

## Шаблон


Показывать только применимые строки, без заполнителей, секретов, служебных ID и внутреннего JSON.

```markdown
**Планирование дня — {общий статус}**

| Параметр | Результат |
| --- | --- |
| Как пользоваться | {По команде / также автоматический утренний список / доступная часть} |
| Источники | {Проверенные системы и личные области; конкретные пробелы} |
| Часовой пояс | {Подтверждённая IANA-зона} |
| Фокус | {Где хранится точный выбор; доступность в следующей сессии} |
| Статусы карточек | {Только фокус / конкретные разрешённые операции по источникам / блокировка} |
| Календарь | {Выбранные календари и подготовка / не выбирался / конкретный предел} |
| Утренний список | {Фактическое время, зона, ближайший запуск и личный канал либо честный статус} |
| Настройки | {Сохранены и доступны следующим запускам / только текущая беседа / что не проверено} |

**Проверено:** {2–4 фактических результата}.

**Требует действия:** {Одна проблема, что она блокирует и ближайший шаг; только при наличии}.

**Первая команда:** «Покажи мои задачи для выбора на сегодня».
```

Если источники/операции имеют разные состояния, использовать компактную таблицу «Источник / Чтение / Действие после выбора». «Выбрано» не означает «изменено», а пробный список не доказывает запись статуса. Не показывать дату или сообщение об автоматической доставке без результата.

При отсутствии нового запуска писать «Расписание включено и проверено; первый утренний список ещё не доставлялся». При отсутствии постоянной привязки не обещать восстановление карты/настроек по памяти чата.

Карточка описывает настройку, не является списком задач и не заменяет финальное отдельное сообщение «Фокус на сегодня / Встречи сегодня».
