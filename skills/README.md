# Скиллы для личного агента

Три переносимых комплекта с мастером первого запуска, личными настройками, карточкой результата и Mermaid-схемой процесса.

| Скилл | Что делает | Первая команда |
| --- | --- | --- |
| [Анализ встреч](analyze-meetings) | Итоги, решения и действия по полному транскрипту; отдельно настраиваемые материалы, задачи и архив | «Настрой анализ встреч» |
| [Силовой тренер](coach-strength-training) | Программа по подтверждённой истории, дневник фактов и необязательный вечерний WHOOP | «Настрой силового тренера» |
| [Планирование дня](plan-daily-tasks) | Личные задачи, выбор фокуса по номерам и календарь с подготовкой | «Настрой планирование дня» |

## Как начать

1. Скачайте нужную папку целиком вместе с `SKILL.md`, `references`, `assets` и `agents`. Один файл `SKILL.md` не содержит все ресурсы.
2. Добавьте папку штатным способом вашего агента, если он поддерживает формат Agent Skills. Если такого импорта нет, предоставьте инструкции и связанные файлы доступным в вашей среде способом. Наличие папки само по себе не подтверждает установку.
3. Напишите стартовую команду из таблицы. Агент проверит доступные возможности и спросит только недостающие предпочтения.
4. По карточке результата проверьте, какие функции доступны, что сохранено и что требует подключения.

Для первого разбора встречи достаточно предоставленного транскрипта. Для тренировочного плана можно начать с своих целей, оборудования и подтверждённой истории. Для планирования дня нужен разрешённый источник личных задач.

## Настройка

| Скилл | Мастер | Карточка результата | Дополнительный ресурс |
| --- | --- | --- | --- |
| Анализ встреч | [Первый запуск](analyze-meetings/references/first-run.md) | [Готовность](analyze-meetings/references/setup-result.md) | [Схема процесса](analyze-meetings/references/flowchart.mmd) |
| Силовой тренер | [Первый запуск](coach-strength-training/references/first-run.md) | [Готовность](coach-strength-training/references/setup-result.md) | [Пустой дневник XLSX](coach-strength-training/assets/training-diary-template.xlsx) |
| Планирование дня | [Первый запуск](plan-daily-tasks/references/first-run.md) | [Готовность](plan-daily-tasks/references/setup-result.md) | [Схема процесса](plan-daily-tasks/references/flowchart.mmd) |

В `assets` находятся пустые примеры. Рабочие настройки, дневник, история и снимки выбора сохраняются отдельно в личном хранилище получателя. Аккаунты, разрешения и расписания автора не переносятся.

Новые подключения начинают в `REVIEW`. Рассылка, изменение карточек, архивирование, WHOOP и автоматические запуски включаются только в согласованной области после проверки. WHOOP необязателен; запросы через IFTTT могут расходовать кредиты по вашему тарифу.

Скиллы задают инструкции агенту. Доступ к сервисам, постоянному хранилищу и фоновым запускам зависит от возможностей конкретной среды.
